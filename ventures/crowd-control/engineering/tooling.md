# Virtual prototyping tooling survey

Task 2026-10-31-003. Checked 2026-10-31 by two research passes (web fetch only; no accounts, no payments). Every price and version is as the cited page states it; "not stated" means the page does not say; "not verified" means the page could not be fetched. These tools change monthly: recheck the date column before relying on a price.

Verdicts are for one need: design and virtually test small crowd-control hardware (water or foam spraying unmanned vehicles, tethered overwatch drones, fire-suppression robots, deployable barriers) before asking a manufacturer for a quote, with free or cheap tools first and no account that holds payment details without a decision (Gate 2).

## Verdict summary
- Use now, no install: tscircuit (browser playground, SPICE transient as the judge for a driver stage), Wokwi Community tier (firmware on a simulated ESP32 or RP2040, projects public), JLCPCB and PCBWay quote pages (quotes only; ordering is Gate 2).
- Use now, Mac install (steps below): KiCad 10.0.8 with its integrated ngspice, FreeCAD 1.1.4 with the FEM workbench and CalculiX for static FEA.
- Later: SimScale Community (browser CFD for a nozzle once a geometry exists; projects public, 10 quantitative runs), OpenFOAM (Multipass or Docker on the Mac), Webots R2025a then Gazebo Jetty (vehicle dynamics once a platform exists), LTspice (only when an Analog Devices part model is needed), HeyPCB Circuit World downloads as KiCad starting points, UGVs FYI as a reference database, Schematik desktop (scaffolding only, no simulator today).
- Skip: Onshape Free (non-commercial, every document public), Blueprint (vendor site unreachable, same category as Schematik), Colorfigures (an illustration skill, not a simulator; the vault note calling it a robotics-electronics simulator is wrong), Asimov 1 as a design reference (humanoid, not a UGV; keep as a licence and business-model reference), Kimi K3.1 Pro (no free tier found; any plan is Gate 2).

## Mac install steps for Oscar (the run stops here; nothing was run)
1. KiCad 10.0.8: https://www.kicad.org/download/macos/, download kicad-unified-universal-10.0.8.dmg, drag KiCad to Applications. Open Schematic Editor, Inspect > Simulator to confirm ngspice runs. macOS 12 or newer.
2. FreeCAD 1.1.4: https://www.freecad.org/downloads.php, Apple Silicon DMG, drag to Applications. Open the FEM workbench, add a CalculiX solver object; if FreeCAD reports no ccx binary, CalculiX must be installed separately (macOS method not verified on any fetched page) and its path set in Preferences > FEM. Rerun the blog's cantilever example and confirm 0.381 mm before trusting the setup: https://blog.freecad.org/2025/09/16/getting-started-with-fem/.
3. tscircuit CLI (optional; the browser playground needs nothing): install Node or Bun, then `npm install -g tscircuit`, then `tsci --help`. https://docs.tscircuit.com/intro/installation
4. Webots R2025a (when a vehicle platform exists): webots-R2025a.dmg from https://github.com/cyberbotics/webots/releases.
5. Gazebo Jetty (only on macOS Sequoia, Apple Silicon): `brew tap osrf/simulation`, `brew trust osrf/simulation`, `brew install gz-jetty`. https://gazebosim.org/docs/latest/install_osx/
6. OpenFOAM 14 (when a nozzle CFD test is written): install Canonical Multipass, then https://openfoam.org/version/macos/.
