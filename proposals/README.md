# Proposals

Changes to the company itself: a new role, a new method or tool, a rule change, a change to the scheduled runs. One file each, written with `playbooks/method-intake.md`, named `YYYY-MM-DD-slug.md`. Each one that recommends adoption appears as a decision `D-###` in the next report. Applied proposals get `status: adopted` and a line in `log/runs.md`; the Friday scorecard reports their measured effect.
