# Queue

One file per task, `YYYY-MM-DD-NNN-slug.md`, written with `playbooks/task-contract.md`. Status lives in the front matter; runs update it in place. Done and dropped tasks stay here for the week's scorecard, then move to `queue/_done/`.

Who may add tasks: Oscar (directly, or by telling Vela), Vela (as a HUB note tagged `for-claude`, imported by the next run), Claude (follow-ups from a run, always with a contract).

Current numbering: the next id is the next `NNN` for today's date.
