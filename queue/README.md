# Queue

One file per task, `YYYY-MM-DD-NNN-slug.md`, written with `playbooks/task-contract.md`. Status lives in the front matter; runs update it in place. Done and dropped tasks stay here for the week's scorecard, then move to `queue/_done/`.

Who may add tasks: Oscar (directly, or by telling Vela or Innovator), Vela and Innovator (as a file here or a HUB note tagged `for-claude`, imported by the next run), only for what Oscar approved or what is on `ventures/_company/cofounder/roadmap.md`. Claude does not open tasks for itself: a follow-up it thinks of is a proposal until Oscar approves it, then Vela or Innovator files it.

Current numbering: the next id is the next `NNN` for today's date.
